# Unsupported Action Target

## Code

- `code`: `unsupported_action_target`
- `status`: `400`
- `url`: `https://developers.glean.com/errors/unsupported-action-target`

## What It Means

The request names an action target that the API does not support.

## Common Causes

- The action target is not accepted for this operation.
- The action target is not valid for the action in the request.

## How To Resolve

### Client Actions

- Read the response `detail` to identify the unsupported action target.
- Change the request to use an action target the operation accepts.

## Retry Guidance

Retrying the same request will continue to fail. Retry only after changing the action target.
