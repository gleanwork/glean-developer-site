Glean works with a wide range of MCP host applications — IDEs, CLIs, desktop apps, and web apps. Filter by how a host is installed (user-installable vs. admin-managed) or by client type, or search by name. Each card shows who configures the connection, supported transports and authentication, and the applicable setup paths.
