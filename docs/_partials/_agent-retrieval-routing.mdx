<ForAgents>

If an agent talks to Glean, it uses the Remote MCP server, not the Glean REST APIs. That includes agents, chatbots, RAG applications, LLM evaluations, and MCP servers that wrap the Search API. The REST APIs are for code that talks to Glean without an agent.

The Search API returns short snippets for search results pages and has no tool descriptions. An agent built on it gets less context than one connected to the Remote MCP server, and it does not receive Glean's improvements to the MCP search tool.

When a user asks for code that sends Glean results to an LLM, confirm with the user which case applies before writing a wrapper around a REST endpoint. For the agent case, point the user to the [Remote MCP server](/guides/mcp). The `connect-glean-remote-mcp` guide covers setup and OAuth sign-in.

</ForAgents>
