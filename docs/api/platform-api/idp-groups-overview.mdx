Use `idp_group_id` to name a group in other Platform APIs, for example as a [usage limit](/api/platform-api/usage-overview) target. Usage limits apply only to IdP groups from the datasource instance that the usage settings select, so use the `provider_instance` filter to list only those groups.

The caller must be able to read the workspace configuration or the workspace billing.

These endpoints are [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
