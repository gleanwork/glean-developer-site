# Users API

The Platform Users API lists the people in the Glean directory. The list includes the same people as the Glean People directory. Inactive users, such as former employees, are left out unless you filter for them.

Use the returned `user_id` values with other Platform APIs, for example as [usage limit](/api/platform-api/usage-overview) targets.

These endpoints are [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
