A trigger is created from a **preset** — a curated event definition such as "a review is requested from me" or "30 minutes before an event starts" — so you describe what you care about rather than assembling a query.

Built-in datasources have a fixed set of presets. Datasources you index through the Indexing API get presets from their schema. See [Custom datasources](/guides/triggers/overview#custom-datasources).

Events are delivered as [Standard Webhooks](https://www.standardwebhooks.com), signed with HMAC-SHA256, and are scoped to what the subscribing user is permitted to see.

These endpoints are [experimental](/experimental/overview) — send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
