Gmail and Outlook search results and chat citations can carry IDs that only work for the caller. Get document by ID cannot resolve those IDs, so retrieve these documents by URL. A Gmail or Outlook URL can still return not found. Federated results and go-link shortcut documents cannot be retrieved yet.

Requests need the `documents:read` scope.

These endpoints are [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
