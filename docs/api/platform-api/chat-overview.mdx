The default response is JSON. To stream, set `stream` to `true` in the JSON body. An `Accept: text/event-stream` header does not replace `stream`.

Configure the bearer credential with the [Platform API authentication guide](/api/platform-api/authentication).

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
