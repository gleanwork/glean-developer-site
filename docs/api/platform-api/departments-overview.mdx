# Departments API

The Platform Departments API lists the departments in the Glean directory. A department is active when at least one active user belongs to it. Inactive departments are left out unless you filter for them. Department names are exact, so names that differ only by case are different departments.

Use departments to name [usage limit](/api/platform-api/usage-overview) targets.

These endpoints are [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
