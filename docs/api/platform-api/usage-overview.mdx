Administrators evaluate any target with `POST /api/admin/usage/limits/evaluate`. Users evaluate themselves, or an agent they can edit, with `POST /api/usage/limits/evaluate`.

Administrative operations require permission to read or edit workspace billing in addition to their OAuth scope. A global administrator role is not required.

Every Usage endpoint except `POST /api/admin/usage/limits` is [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

Use the [Users](/api/platform-api/users-overview), [Departments](/api/platform-api/departments-overview), [IdP Groups](/api/platform-api/idp-groups-overview), and [Agents](/api/platform-api/agents-overview) APIs to find the identifiers that usage limit targets use.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
