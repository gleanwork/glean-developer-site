These endpoints leave out dynamically registered clients and Glean's own clients, such as Glean Desktop. To set a [usage limit](/api/platform-api/usage-overview) for a client, use its `ai_gateway.usage_client_id`.

Requests need the `admin.oauth.clients:read` scope, and the caller needs admin read or billing read permission.

These endpoints are [experimental](/experimental/overview). Send `X-Glean-Include-Experimental: true` on each request, or they are not exposed.

For error responses, see [Platform API Errors](/errors) for the shared ProblemDetail code reference and remediation guidance.
