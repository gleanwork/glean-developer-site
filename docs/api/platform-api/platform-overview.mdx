# Platform API

The Platform API is Glean's recommended API for new application integrations. Build modern search, agent, skills, and chat experiences over your organization's connected content.

:::tip Recommended for new integrations

Start with Platform API whenever the capability you need is available and its stability level fits your use case. Review the applicable stability notices before adopting a capability or endpoint. Use [Client API](/api/client-api) for existing integrations or capabilities that have not yet moved to Platform API.

:::
