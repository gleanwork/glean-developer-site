# Platform API

The Platform API is Glean's recommended API for new application integrations. Build modern search, agent, skills, and chat experiences over your organization's connected content.

:::tip Recommended for new integrations

Start with Platform API whenever the capability you need is available and its stability level fits your use case. Search, Chat, and Skills are currently experimental. Use [Client API](/api/client-api) for stable existing capabilities, existing integrations, or capabilities that have not yet moved to Platform API.

:::

## Start building

<Steps>
  <Step title="Authenticate">
    Follow the [Platform API authentication guide](/api/platform-api/authentication) to configure one of the supported bearer-token methods.
  </Step>

  <Step title="Try a capability">
    Start with the [Platform API getting-started guide](/api/platform-api/getting-started), then choose Search, Agents, Skills, or Chat.
  </Step>

  <Step title="Use the reference">
    Browse the endpoint reference for request parameters, schemas, examples, and responses.
  </Step>
</Steps>
