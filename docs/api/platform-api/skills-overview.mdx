# Skills API

:::experimental

Expect changes and instability while the Platform Skills API is experimental. [Learn how experimental APIs work](/experimental/overview).

:::

The Platform Skills API lets applications discover, validate, import, synchronize, version, and manage skills that can be used with Glean.
