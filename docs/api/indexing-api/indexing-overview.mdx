# Indexing API

The Indexing API makes content from internal tools, on-premises systems, and custom applications searchable in Glean. Use it to manage datasources, index content, apply permissions, and keep search results current.

## Indexing workflow

<Steps>
  <Step title="Create a datasource">
    Set up a datasource to organize the content you want Glean to discover. Follow the [datasource setup guide](/api-info/indexing/getting-started/setup-datasource).
  </Step>

  <Step title="Index content">
    Index content with the [Documents](/api/indexing-api/documents-overview), [People](/api/indexing-api/people-overview), and [Permissions](/api/indexing-api/permissions-overview) references.
  </Step>

  <Step title="Apply permissions">
    Index permissions and validate document access so users only see content they are authorized to view.
  </Step>

  <Step title="Validate and troubleshoot">
    Use the [Indexing API getting-started guide](/api-info/indexing/getting-started/overview) and the troubleshooting guides in the sidebar to verify your datasource and indexed content.
  </Step>
</Steps>

## Capabilities

<CardGroup cols={2}>
  <Card title="Datasources" icon="Database" href="/api/indexing-api/datasources-overview">
    Create, configure, and manage the datasources that hold your content.
  </Card>

  <Card title="Documents and data" icon="FileText" iconSet="feather" href="/api/indexing-api/documents-overview">
    Index documents individually or in bulk, then update and remove them as content changes.
  </Card>

  <Card title="People" icon="Users" iconSet="feather" href="/api/indexing-api/people-overview">
    Index employees and teams used by Glean's people directory and retrieval experiences.
  </Card>

  <Card title="Permissions" icon="Shield" href="/api/indexing-api/permissions-overview">
    Index users, groups, and memberships that control access to indexed content.
  </Card>
</CardGroup>

## Authentication

The Indexing API uses Glean-issued tokens. Start with the [Indexing API authentication guide](/api-info/indexing/authentication/overview) before sending your first request.

## Cross-datasource enrichment

[Custom Metadata](/api-info/indexing/custom-metadata/overview) is grouped with Indexing API guidance because it enriches indexed content and uses Glean-issued credentials, but it uses the distinct `/rest/api/index/custom-metadata/...` base path. It can attach metadata to documents from any datasource, including native connectors, without re-indexing the source document.
