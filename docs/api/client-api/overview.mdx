# Client API

The Client API provides existing REST capabilities for building user-facing Glean experiences, including search, chat, agents, document access, and content management.

:::note When to choose Client API

For new integrations, start with the [Platform API](/api/platform-api). Choose Client API when you need an existing Client API capability that is not yet available in Platform API or when you are maintaining an existing integration.

:::
