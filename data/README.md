# data/

Generated files. Do not edit them by hand.

| file | generated by | from |
| --- | --- | --- |
| `cookbook-registry.json` | `pnpm registry:sync` | `gleanwork/glean-cookbook`'s built `registry.json` |
| `cookbook-plugin.json` | `pnpm registry:sync` | that repo's `.claude-plugin/marketplace.json` |

`src/data/recipes.json` is compiled from `cookbook-registry.json` by
`pnpm recipes:compile`, and is likewise generated.

## Why this file exists

These are committed and not gitignored, because the build needs them and they are
fetched on demand rather than during a build. JSON cannot carry a comment saying so,
so they look hand-maintained: searching for a recipe id finds them, and adding an
entry alongside the others renders a correct-looking page.

It is then deleted by the next sync, which writes whatever the cookbook says and
knows nothing about local additions. Four pull requests hit this.

`scripts/check-generated-recipe-data.mjs` now fails CI when the sync and the compiled
output disagree, which is what a hand-added recipe looks like.

## Adding a recipe

Recipe metadata is authored in `gleanwork/glean-cookbook` at
`recipes/<id>/recipe.json`. See the Cookbook recipes section of `AGENTS.md` at the
repo root for the full path.
