Api-client-go v0.17.6 includes 4 breaking removals, 2 changes.

{/* truncate */}

## Action Required

- Update callers of `chat.create()` to stop using `request.Request.Text`.
- Update callers of `chat.create()` to stop using `response.Output[].Content[].StructuredOutput`.
- Update callers of `chat.createstream()` to stop using `request.Request.Text`.
- Update callers of `chat.createstream()` to stop using `response.[].union(RESPONSE_COMPLETED).Data.Response.Output[].Content[].StructuredOutput`.

## Changes

- Changed `response.Results[].Reason` on `triggers.searchevents()`.
- Changed `response.Results[].Reason` on `triggers.searchpresetevents()`.

## Breaking Changes

- Removed `request.Request.Text` from `chat.create()`.
- Removed `response.Output[].Content[].StructuredOutput` from `chat.create()`.
- Removed `request.Request.Text` from `chat.createstream()`.
- Removed `response.[].union(RESPONSE_COMPLETED).Data.Response.Output[].Content[].StructuredOutput` from `chat.createstream()`.
